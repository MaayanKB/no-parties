# party-spam

קיבלתם הודעה מבן גביר? מלפיד? מאיזנקוט? מכולם באותו יום?

הם לא קיבלו את המספר שלכם בטעות. הוא יושב במאגר, ולפעמים לידו גם הערכה למי תצביעו.
החוק מאפשר לכם לדרוש מהם למחוק אותו. הדף הזה כותב את המכתב, ואתם רק לוחצים "שלח".

ולא, לענות "הסר" ל-SMS לא מוחק אתכם מהמאגר.

**👈 [לדף](https://no-parties.pages.dev/)**

## מה קורה אחרי ששולחים

למפלגה יש 30 יום להסיר אתכם מהמאגר ולהודיע לכם על כך. אם עברו 30 יום בלי תשובה, אפשר להגיש תביעה לבית משפט השלום.
שמרו את המייל ששלחתם ואת התשובה, אם תגיע.
כל הפרטים: [הסרת פרטים של בעלי זכות בחירה ממאגרי המידע של המפלגות, בכל זכות](https://www.kolzchut.org.il/he/הסרת_פרטים_של_בעלי_זכות_בחירה_ממאגרי_המידע_של_המפלגות).

## מאיפה הנתונים

כתובות המפלגות נלקחו מ[מאגר רשם המפלגות](https://www.gov.il/he/departments/dynamiccollectors/parties-db) במשרד המשפטים, ובחלק מהמקרים ממדיניות הפרטיות שבאתרי המפלגות עצמן.
אילו רשימות מופיעות: כל רשימה שעברה את אחוז החסימה לפחות בסקר אחד ב-2026.
הנתונים עודכנו ב-19.10.2026.

שום מידע שתמלאו בדף לא יוצא מהדפדפן. אין לראות בדף ייעוץ משפטי.
