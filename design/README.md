# Design sources

Source files behind the assets the page uses. The page itself does not load anything from this folder.

| File | What it is |
|---|---|
| `illustration-original-chatgpt.png` | The voter illustration as generated by ChatGPT. Its "transparent" background is a checkerboard painted into the pixels. |
| `illustration-cutout-fullres.png` | The same illustration with the checkerboard removed (real transparency), full resolution. |
| `cutout.py` | The script that removes the checkerboard: `python3 cutout.py illustration-original-chatgpt.png out.png`. |
| `logo-haser-wordmark.svg` | The "הסר!" logo: Karantina letters as paths, with the hand-drawn pen loop. Colours come from the page (`currentColor`, `--logo-loop`). |
| `logo-haser-favicon.svg` | The favicon: a circled "!" on navy. |

The web version of the illustration is `art/voter.webp` (cropped, 838×900, WebP). The share image is built from `og/og.html` into `og.png`.
