# Logo sources

Text-only logos from Wikimedia Commons, marked PD-textlogo (public domain: simple text, not a copyrightable work).
They are shown only to identify each list. The page is not affiliated with or endorsed by any party.
Logos with graphic elements, or whose current version is not free, are deliberately not used.
Remove any logo immediately if its owner asks.
